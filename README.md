# 인벤토리 매니저

PRM 인벤토리에서 누이 아이템을 정리하고, 교환 목록과 구해요 이미지를 만드는 Tampermonkey 사용자 스크립트입니다.

이 프로젝트는 PRM이 제공하거나 보증하지 않는 비공식 Tampermonkey 사용자 스크립트입니다.

## 설치

1. 브라우저에 Tampermonkey를 설치합니다.
2. [인벤토리 매니저 설치](https://raw.githubusercontent.com/neo5322/inventory-manager-userscript/main/inventory-manager.user.js)를 엽니다.
3. Tampermonkey 설치 창에서 설치를 선택합니다.

대상 페이지: `https://prm.dothome.co.kr/my_page*`

## 업데이트

개요 화면의 **업데이트 확인**으로 GitHub 안정 배포본과 현재 설치 버전을 비교할 수 있습니다. 새 버전이 있으면 **업데이트 설치** 링크가 표시됩니다. 시작할 때도 12시간 간격으로 조용히 확인하며, 인벤토리 데이터는 업데이트 확인에 보내지 않습니다.

스크립트에는 고정된 `@updateURL`과 `@downloadURL`이 설정되어 있습니다. Tampermonkey 스크립트 설정에서 업데이트 확인 주기와 자동 설치 여부를 조정할 수 있습니다. 업데이트를 수동으로 설치하려면 화면에 표시된 **업데이트 설치**를 선택하세요.

## 데이터와 설정

- 화면 설정, 누이 분류와 선택, 마지막으로 정상 조회한 구해요 목록은 현재 브라우저의 PRM 사이트 `localStorage`에 저장됩니다. 브라우저 저장소를 지우면 이 설정과 목록 캐시도 삭제됩니다.
- 인벤토리 데이터는 PRM에서 조회하며, GitHub 목록·버전 확인 요청으로 보내지 않습니다.
- 구해요 목록은 이 저장소의 GitHub Raw manifest와 출처별 JSON 파일에서 가져옵니다. 새 목록을 읽지 못하면 브라우저에 저장된 마지막 정상 목록을 사용합니다.
- 시작 시 12시간 간격으로 GitHub의 안정 배포본에서 `@version`을 확인합니다. 이 확인은 버전 정보를 비교하며, 자동 설치 여부는 Tampermonkey 설정을 따릅니다.

## 기능

- 인벤토리 추적과 누이 교환 가능/불가 분류
- 호박 동상 트로핗, 유령 은상 트로핗, 제물 티켓의 전체·캐릭터별 보유량 대시보드
- 기존 보유 아이템과 폴더를 참고하는 자동 정리 제안 및 선택 규칙 기억
- 모든 캐릭터의 같은 누이를 1개 남기고 초과분을 교환 가능으로 설정하는 원클릭 기능과 별표 소장 예외
- 교환 PNG에서 같은 누이를 한 카드로 합쳐 합산 수량과 보유 캐릭터 표시
- 일반 누이 선택 및 구해요 이미지 생성
- 누이 종류, 번호, 캐릭터 별칭 기준 자동 정렬
- 이미지 페이지 분할, 간략화, 개별 PNG 및 선택형 ZIP 저장

구해요 목록 데이터는 이 저장소의 [목록 manifest](catalog/nui-wanted/manifest.json)와 출처별 JSON 파일에서 읽습니다. 처음 사용할 때 인터넷 연결이 필요하며, 이후 목록을 갱신하지 못하면 브라우저에 저장된 마지막 정상 목록을 표시합니다. 새로운 공식 목록의 추가 방법은 [데이터 안내](catalog/nui-wanted/README.md)에 있습니다.

자세한 변경 사항은 [업데이트 노트](CHANGELOG.md)를 참고하세요.
